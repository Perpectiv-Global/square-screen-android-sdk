SquareScreenLogger

interface SquareScreenLogger

Pluggable logging interface. Pass an implementation to io.squarescreen.core.config.SquareScreenConfig.logger at init time.

The SDK never calls android.util.Log directly — all internal logging goes through this interface.

Pass null (the default) for completely silent operation in all build types.
