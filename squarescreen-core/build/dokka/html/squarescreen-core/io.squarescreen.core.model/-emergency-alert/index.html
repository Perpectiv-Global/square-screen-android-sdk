EmergencyAlert

data class EmergencyAlert(val id: Int, val uuid: String, val companyId: Int, val title: String, val message: String, val backgroundColor: String, val textColor: String, val targetScope: String, val isActive: Boolean, val startedAt: String, val endedAt: String? = null)

An active emergency broadcast targeting this device.

Parameters

id

Server-assigned integer ID.

uuid

Universally unique identifier for this broadcast.

companyId

ID of the company that issued the broadcast.

title

Short title displayed prominently on the overlay.

message

Body text of the emergency message.

backgroundColor

Hex color string for the overlay background (e.g. "#FF3B30").

textColor

Hex color string for the overlay text (e.g. "#FFFFFF").

targetScope

Scope of this broadcast ("all", "workspace", "group", or "device").

isActive

Whether this broadcast is currently active.

startedAt

ISO 8601 timestamp when the broadcast started.

endedAt

ISO 8601 timestamp when the broadcast ended, or null if still active.
