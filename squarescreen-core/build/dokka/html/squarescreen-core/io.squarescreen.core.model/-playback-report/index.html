PlaybackReport

@Serializable
data class PlaybackReport(val mediaUuid: String, val playlistUuid: String?, val scheduleUuid: String?, val startedAt: String, val endedAt: String, val durationSeconds: Int, val completed: Boolean)

Proof-of-play report sent to the server after a playlist item finishes displaying.

Parameters

mediaUuid

UUID of the media file that was played.

playlistUuid

UUID of the playlist this item belongs to, if known.

scheduleUuid

UUID of the schedule driving playback, if known.

startedAt

ISO 8601 timestamp when the item started displaying.

endedAt

ISO 8601 timestamp when the item finished displaying.

durationSeconds

Actual number of seconds the item was displayed.

completed

Whether the item played to its full duration without interruption.
